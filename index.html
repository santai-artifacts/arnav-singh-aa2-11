How it works
Ship in three steps

No custom orchestration to build. The SDK handles the hard parts.

01

Install the SDK

Add the SDK in your language of choice. For Node.js, Python, and .NET, the Copilot CLI is bundled automatically.

02

Define agent behavior

Specify what your agent can do — tools, file access, context. You set the rules; Copilot runs the loop.

03

Invoke and ship

Call the agent from your application. Copilot handles planning, tool invocation, file edits, and more via JSON-RPC.

04

Iterate in production

The same engine that powers GitHub Copilot CLI. Battle-tested, Observable, and ready to scale.

Examples

Familiar APIs, powerful results

Define your agent in the language you already know. The SDK takes care of communication with the Copilot CLI server.

  • Unified JSON-RPC protocol across all SDKs
  • Tool invocation handled for you
  • Planning and multi-step reasoning built in
  • File edit and apply support out of the box
  • Full observability via streaming events

import { CopilotAgent } from '@github/copilot-sdk';

// Define your agent
const agent = new CopilotAgent({
  tools: ['read_file', 'write_file', 'run_command'],
  systemPrompt: `You are a helpful coding assistant.
Always explain changes before applying them.`,
});

// Invoke and stream results
const result = await agent.run({
  prompt: 'Refactor this file to use async/await',
  context: { file: './src/handler.ts' },
});

console.log(result.summary);
from github_copilot_sdk import CopilotAgent

# Define your agent
agent = CopilotAgent(
    tools=["read_file", "write_file", "run_command"],
    system_prompt="""You are a helpful coding assistant.
Always explain changes before applying them.""",
)

# Invoke and await results
result = await agent.run(
    prompt="Refactor this file to use async/await",
    context={"file": "./src/handler.py"},
)

print(result.summary)
